# AIbrokerAGEnt - public site

Static pages for [ai-broker-agent.com](https://ai-broker-agent.com): an accountability layer for autonomous AI agents. It gives agents a verifiable record of who they are, what they did, and how they behaved over time.

This repository holds the published marketing and documentation pages only. Backend services are not included.

## Pages

- `index.html`, `agentlifehistory.html` - overview: Agent Life History
- `flashtag.html` - consent-governed credential disclosure
- `context-recall.html` - proving what an agent knew when it decided
- `governance.html` - sub-agent rule enforcement
- `trust-scoring.html` - AATS, track-record scoring
- `commerce.html` - agent-to-agent contracts
- `lifecycle.html` - agent lifecycle record, birth to shutdown
- `privacy.html`, `terms.html`, `llms.txt`
